PlayToStar（实况起点）iOS 首次构建/提审说明 — Codemagic 方案A
版本 1.66.1（构建号自动，>=25）  Bundle ID: com.playtostar.app
========================================================

【本包已包含的审核硬门槛】
  1. Sign in with Apple（iOS 原生，黑底 Apple 按钮；后端统一验签 POST /api/auth/apple）
  2. 拉黑发布者（作者菜单拉黑、黑名单管理页；被拉黑者内容自动隐藏）
  3. （此前已具备）内容举报、敏感词、管理员审核后台、账号注销

--------------------------------------------------------
一、Apple Developer 后台（必做，一次性）
--------------------------------------------------------
1. 登录 https://developer.dark/account  → Certificates, Identifiers & Profiles
2. Identifiers → 找到 com.playtostar.app（没有就新建 App ID）
3. Capabilities 勾选【Sign In With Apple】并保存
   （iOS 原生 Apple 登录只需这一项；网页版 Apple 登录才需额外注册 Services ID）
4. 确认 Bundle ID 与本包一致：com.playtostar.app

--------------------------------------------------------
二、Codemagic 配置（必做）
--------------------------------------------------------
1. 新建 App，选择本包源码（上传 zip 或关联 Git，codemagic.yaml 在根目录）
2. Team settings → Developer Portal → Manage keys：
   上传 App Store Connect API Key（.p8），记下你给它起的名字
3. 打开 codemagic.yaml，把 integrations.app_store_connect 的值
   改成上一步的 Key 名称（默认：codemagic）
4. 运行 workflow「iOS Release」：
   - 自动 npm ci → cap sync ios → 自动签名 → 构建 IPA → 上传 App Store Connect
   - 构建号：脚本已保证首次为 25，之后随 Codemagic 计数器递增（每次唯一）
5. 当前 submit_to_testflight: false（只上传、不自动分发）
   上传成功后在 App Store Connect → TestFlight 把自己加为“内部测试”

--------------------------------------------------------
三、真机/TestFlight 先验证（再提审）
--------------------------------------------------------
  □ Apple 按钮可正常拉起 Face ID/Touch ID 登录，退出后可再登录
  □ 评论/帖子作者菜单可拉黑；设置→黑名单管理可取消
  □ 被拉黑账号的评论/帖子在前台不可见
  □ 举报、账号注销路径正常

--------------------------------------------------------
四、提交审核前在 App Store Connect 补齐
--------------------------------------------------------
  □ App 截图（各尺寸）、描述、关键词、分类（体育）
  □ 年龄分级
  □ App 隐私问卷（本 App 账号/UGC 相关数据项如实填报）
  □ 审核备注：可注明为 eFootball 玩家自建数据库工具，无付费/充值入口

--------------------------------------------------------
五、常见驳回点对照
--------------------------------------------------------
  - 有第三方登录却没有 Apple 登录  → 已补
  - UGC 无举报/拉黑/拉黑管理       → 已补
  - 无账号注销入口                → 已具备（设置内）
  - 登录信息/权限说明不清         → 提审文案中说明用途
